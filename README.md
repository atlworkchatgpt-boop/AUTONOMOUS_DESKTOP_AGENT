# AUTONOMOUS DESKTOP AI - MAX EDITION

Created & owned by Shreyansh Ray.

A local-first Windows AI assistant powered by Ollama.

## Features

- AI chatbot
- Local Ollama model
- Windows application control
- Browser automation
- Chrome support
- Google search
- Browser navigation
- Browser typing/clicking
- Files and folders
- Project inspection
- Code reading
- Code editing with automatic backups
- Keyboard
- Mouse
- Clipboard
- Screenshots
- Process information
- System information
- Safe terminal
- Chat-context import
- Owner authentication
- Startup authentication
- Two-step destructive-action confirmation

## Authentication

Starting programs:
gngaistart

Computer-changing / personal-information actions:
gngai

Delete / install / close:
gngai
+
confirmation 1
+
confirmation 2

## Chat Context

Put exported/copied conversation text inside:

data\chat_context\chat_context.txt

Then tell the assistant to read it.

## Start

python main.py
