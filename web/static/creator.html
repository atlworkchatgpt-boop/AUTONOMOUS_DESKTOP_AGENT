Creator and owner of Autonomous AI

Hi! I created and own Autonomous AI as a personal learning and practice project.

I built this project in roughly three days while practicing Python, web development, AI APIs, databases, authentication, autonomous-agent concepts, and chess integration.

Autonomous AI is a non-profit practice project. Its purpose is learning, experimentation, and exploring what can be built with modern software and AI technology.

The project is still evolving and some features are experimental.
